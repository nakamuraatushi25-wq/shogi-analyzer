# shogi-analyzer

棋譜（KIF）から戦法と囲いを自動判定するライブラリです。上達ソフトの分析エンジンの土台になります。
TypeScript で書いてあり、外部ライブラリは使っていないので、ブラウザでも Node でもそのまま動きます。

## 使い方

```sh
npm test                                   # テスト（Node 22.18 以上）
npm run classify -- path/to/games.kif      # 複数局の KIF を判定して一覧表示
```

```ts
import { parseKif } from './src/kif.ts';
import { classifyOpening } from './src/opening.ts';
const result = classifyOpening(parseKif(kifText));
// result.opening  例: "四間飛車 vs 居飛車持久戦" / "角換わり" / "矢倉（先手右四間飛車）"
```

## 判定ルール（すべてその側から見た座標）

- 飛車：40手目まで、かつ金銀以上の駒が初めて取られるまでの、飛車の最初の一手で決める。
  2八から横へ動いたときだけ振り飛車などとみなし、浮き飛車からの横移動や、玉を左（6筋より左）に囲ってから飛車を左へ回す手は居飛車のままとする。
  5筋＝中飛車、6筋＝四間、7筋＝三間（その後7六に上がれば石田流）、8筋＝向かい飛車、4筋＝右四間、3筋＝袖飛車。
  3四の歩を飛車で取った場合は横歩取り。
- 角交換：30手目までに両者が角（馬）を取ったら角交換。
- 囲い：金銀以上の駒が初めて取られる直前（遅くとも60手目）の局面で、玉と金銀の位置から判定する。
  穴熊、矢倉（金矢倉・菊水矢倉・矢倉（未完成））、左美濃、銀冠、高美濃、本美濃、片美濃、カニ囲い、舟囲い、居玉。
- 対抗形は、居飛車側が穴熊・矢倉・美濃系を組んでいるか、金銀以上の駒が初めて取られるのが42手目より後なら「持久戦」、それ以外は「急戦」。
- 相居飛車は、横歩取り → 角換わり → 矢倉 → 雁木 → 相掛かり の順で判定する。

## 判定ルールの検証

[bioshogi](https://github.com/akicho8/bioshogi)（SHOGI-EXTEND の戦法・囲い判定）と、lishogi の 2,039 局（対局者ごとに1局）で突き合わせた。
bioshogi は AGPL のため、コードや定義データは取り込まず、判定結果の照合だけに使っている。

| 項目 | 一致率 |
|---|---|
| 相居飛車・対抗形・相振り飛車 | 94.8% |
| 振り飛車の種類（中飛車・四間・三間・向かい） | 94.4% |
| 対抗形の急戦・持久戦 | 88% |
| 美濃系・穴熊・金矢倉 | 82〜100% |

## 勝ち局・負け局の駒の動かし方の集計

```sh
# 1. 集めた棋譜を1局1行の一覧にする（戦型・囲い・段級位・勝敗・駒ごとの回数入り。約6分）
node scripts/build-index.ts data/lishogi data/lishogi/index.jsonl
# 2. 戦型（自分の飛車の位置別）× 段位帯 × 勝ち/負けで集計する（約20秒）
node scripts/piece-trends.ts data/lishogi/index.jsonl data/trends.json
# 3. 勝ち局と負け局で差の大きい駒を表にする（最低局数・上位件数）
node scripts/trends-report.ts data/trends.json 300 3
```

- 駒ごとに、盤上で動かした回数と打った回数を数える。成駒は元の駒に含める。
- 対局全体（1手あたりの割合）と、60手目まで（回数）の2通りで比べる。
- 段位帯は 6級以下・5〜1級・初段〜二段・三段〜四段・五段以上。
- 差の大きさは効果量 d（勝ち局の平均 − 負け局の平均を、合わせた標準偏差で割ったもの）で表す。|t| が 3 以上のものだけを載せる。

## 駒を取ったマスと勝ち負けの集計

```sh
# 一覧（build-index.ts の出力）から、戦型ごとに駒を取ったマス別の勝ち・負け局数を集計する（手数の上限）
node scripts/capture-trends.ts data/lishogi/index.jsonl data/captures.json 60
# 最初に駒を取ったマス別の勝率（9×9）と、上限までに取ったマス別の勝率の高い・低いマスを表にする
node scripts/capture-report.ts data/captures.json 全体 10 200
```

マスは駒を取った側から見た座標（後手なら盤を180度回す）。下が自陣になる。

```sh
# 何手目にどこ（敵陣・中段・自陣）で取ったか、どちらが先に取ったか、何の駒をどの駒で取ったか（60手目まで）別の勝率
node scripts/capture-timing.ts data/lishogi/index.jsonl 6 300
```
